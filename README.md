# Exam Arena (CBT Practice System)

Exam Arena is a LAN-based CBT practice system for **JAMB / WAEC / NECO** preparation.
One computer runs the **server**, and students connect from other computers/phones on the same network using a browser.

## What it does
- Practice exams by subject
- Timer-controlled CBT sessions
- Instant results + corrections
- Printable result slip
- Works offline (LAN) once installed
