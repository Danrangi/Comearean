[3] HOW STUDENTS CONNECT
-------------------------------------------------------------------
You do not need to install this software on every student computer.
It runs on the SERVER, and students connect via the network.

1.  Ensure all computers are connected to the same Network/Router.
2.  On the Server (Black Window), look for the line that says:
    
    [*] Network Access: http://DESKTOP-XYZ:8080

3.  Go to a Student Computer, open Chrome/Edge, and type that 
    exact address into the top address bar.

    Example: http://DESKTOP-NAME:8080

[5] TROUBLESHOOTING
-------------------------------------------------------------------
ISSUE: Students cannot connect to the server.
FIX:   1. Check if the Server PC and Student PC are on the same Wi-Fi.
       2. On the Server PC, turn off "Windows Firewall" temporarily 
          or allow port 8080.

ISSUE: "License Expired" error.
FIX:   Check your computer date and time. If the date is correct 
       and it still fails, your license has expired. Contact support.
